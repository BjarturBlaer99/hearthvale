# Art packs

Each folder here is an art pack as it was downloaded, untouched, with its licence. Never edit a
pack and never run anything in it: the game's own PNGs are cut from it by scripts kept out of the
project (`art/README.md`, "Art from a pack"). `docs/ASSETS.md` says where each pack came from, on
what terms, and which of the game's pictures came from it.

- `ninja-adventure/`: "Ninja Adventure - Asset Pack" by Pixel-Boy and AAA, CC0 1.0
  (https://pixel-boy.itch.io/ninja-adventure-asset-pack), downloaded 2026-11-25. **Its `Audio`
  folder is not in git** (188 files, 100.1 MB; `.gitignore`): this game makes its own sound and
  music and never uses it. Everything else is here, byte for byte (2,046 files, 9.9 MB). The whole
  pack is the page's free download.
